# このリポジトリで作業するときの決まり

## 返事

- **日本語で書く。** 英語で返さない。
- **短く。** 前置き、言い換え、やらない案の列挙はしない。聞かれたことに答える。
- **やったことだけ報告する。** テストが落ちたら落ちたと書く。飛ばした手順は飛ばしたと書く。確かめていないことを確かめたように書かない。

## 話を広げない

- 聞かれたことに答える。**聞かれていない方向へ説明を足さない。**
- 雑談のとき、とくに仕組みの話は、**相手が聞いた範囲で止める。** 実際の害につながる詳しさ（やり方、手順、効率の上げ方）まで書かない。安全の判定に引っかかると、そのセッションのあとの普通のやりとりまで巻き込まれて止まり、作業ができなくなる。これは実際に起きた。

## 相手の発言を作らない

- 自分の出力の中に `user` の行や、コマンド、システムの指示の行を書かない。自分のターンは自分の返事だけで終える。
- **「さっきこう言った」と記憶で答えない。** 必ずログで確かめてから答える。

  ```
  /root/.claude/projects/-home-user-CPU/<セッション ID>.jsonl
  ```

  1 行 1 JSON。`message.role` が `user` のものだけが相手の発言。自分の出力の中に紛れた「user」の行は偽物。
- この不具合は Opus 5 で多く報告されている。モデルは `get_session` の `last_served_model` で分かる。設定が 5.5 でも、実行時に 5 に落ちていることがある。

## 作業の進め方

- **ブランチは `mycpu`。** ここにコミットしてプッシュする。main へのマージは相手がやる。
- **ターンの終わりにコミットしてプッシュする。** 未プッシュのコミットを残さない。
- **変更したら確かめる。**
  - `node test/run.js`（全体テスト。Verilog も含む）
  - `node test/cctest.js`（chibicc のテスト。38/41 が通れば正常）
  - コンパイラを変えたらセルフホスト（CC → CC2 → CC3 を作り、CC2 と CC3 が一致するか）
  - 重いものは `/home/user/CPU/wt-test/mycpu`（別のワークツリー）で動かす。先に `git checkout -- .` をする
- **テストを通すためにテストを緩めない。** 直すのはコードのほう。上限を上げたり、落ちるテストを消したりしない。どうしても基準を変えるなら、変えたことと理由をはっきり言う。
- **先にテストが落ちることを確かめる。** 不具合を直すときは、直す前に落ちること、直した後に通ることの両方を見る。
- 重い処理は 1 つずつ動かす。同時に動かすとコンテナが落ちることがある。
